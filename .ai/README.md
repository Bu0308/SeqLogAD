# SeqLogAD orchestration metadata

This directory is a pointer-only coordination layer. It does not replace, amend, or interpret the frozen scientific contract, and it does not authorize scientific execution.

Start with [`primary-context.md`](primary-context.md), then use [`task-routing.md`](task-routing.md) and the smallest relevant file under [`context-packs/`](context-packs/). Roles and model assignments are in [`agent-roles.md`](agent-roles.md). Every implementation flows through T8 QA & Reproducibility before Primary acceptance/rejection. Every handoff uses [`handoff-template.md`](handoff-template.md); conflicts use [`escalation.md`](escalation.md).

Active truth is identified by [`../configs/active-state.yaml`](../configs/active-state.yaml). Historical plans remain provenance only and cannot override the active v1.1 stack.
