## Method and evidence boundary

**SEQLOGAD-SPECIFIC PROTOCOL DECISION:** single-message causal denoising reconstruction.
Use only the frozen normalizer's `normalized_message`, no EventID, architecture,
rank, path, session or neighbouring events as model input. Deterministically mask
30% of whitespace-delimited words (at least one) using literal `[MASK]` text; add no
vocabulary entries. Input is BOS + restoration prompt/corrupted message + original
message. Targets are the original message tokens and EOS only at a genuine complete
message boundary. Prompt and padding labels are -100. Standard shifted causal
cross-entropy is averaged over supervised target tokens, then equally over messages.
There is no bidirectional MLM claim. Corruption is deterministic by text/seed, also
at validation/inference. Within-message token order remains necessary for meaning;
inter-event sequence order is not provided. No cross-record packing or KV sharing.

The simplest reconstruction formulation follows the existing playbook. This exact
objective, mask rate, scoring rule and budget are project decisions, not claimed
as a replication or paper-established optimum. It can learn a copy shortcut or
frequent abnormal content; raw likelihood is not guaranteed semantic correctness.
The distinction must later be tested with semantic/OOV controls and diversity
ablations; P2.1 does not claim anomaly AP/FAR or cross-system performance.

**Source population is label-free, not certified normal.** No labels may filter
records or set loss/selection/thresholds. Contamination remains possible. This is
consistent with the P2.0 source-only contract, not a new clean-normal permission.
REP-DG-001/DANN is conditional and deferred; no source-alignment result is claimed.

## Configuration and practical budget

`configs/models/semantic-v1.yaml` owns experimental defaults. Rank16/alpha32 limits
adapter capacity; attention q/k/v/o projections give an explicit, bounded target
set. Dropout0.05 provides mild regularization. LR1e-4, AdamW, no weight decay,
25-step warmup and linear decay, clip norm1 form a conservative starting recipe.
These are **engineering initial conditions**, not scientifically optimized values.

Context512 includes prompt and reconstruction target. Long messages use a recorded
decreasing head-word prefix until both fit; omitted suffix has zero coverage and
no fabricated EOS. Empty/unencodable messages abstain and are counted in coverage.
Literal upstream control-token spellings are escaped to ordinary text.

The entire authorized source membership is materialized. Training uses a reproducible
seeded rank-subset cap of4096 records/source; validation128/source. This caps cost and reduces
source-size dominance without new partitioning or label selection. All selected
ranks and coverage/rejections are exported. Uniform independent message sampling,
seed42, microbatch1 × accumulation16, max500 optimizer steps (8000 sampled message
presentations) is a PREFLIGHT/PILOT engineering budget; it is not a full corpus epoch or the
final scientific training budget. Completing this run does not complete scientific
P2.1 or establish sufficient sample coverage. Final training requires a separately
preregistered sample/token budget, seeds, stopping criteria and validation adequacy
assessment; the 4096/128 caps have no demonstrated scientific sufficiency. Each run
records overrides; subsequent tuning requires a distinct run/config. Checkpoint
selection uses only mean source-validation reconstruction NLL. No threshold fitting.

Native BF16 preferred, FP16 conditional finite preflight, FP32 trainable adapter and
optimizer state. Default QLORA_NF4_DOUBLE_QUANT; LOW_MEMORY mode uses the same
quantizer and the frozen <=1024 ceiling. Actual VRAM is unmeasured until Colab.
Prefer native-BF16 L4 24GB or A100; T4 16GB is conditional, not guaranteed to fit or
remain numerically stable. Never silently change precision/model/mode on failure.

## Data and fail-closed validation

Create with `.venv/bin/python scripts/prepare_semantic.py`. No overwrite of an
existing final bundle. Interrupted `.building` caches can be resumed only after
checking raw corpus/stream/normalizer identities, every rank/segment and normalized
content hash against Phase1. No learned cross-fold cache is used.

The builder reuses frozen G0-bound folds and segmentation. It reconstructs the
stable timestamp/file order to map exact source ranks, verifies stream content, and
normalizes only selected EARLY/MID records. GUARD/LATE/excluded records are not
semantic payloads. No ground-truth sidecar is opened; BGL adapter strips the inline
marker before message parsing. Source provenance uses neutral file ordinals/hashes,
not label-bearing filenames. Physical data is copied into each applicable fold.

Required view: `data/phase2/folds/<fold_id>/semantic/{train,val}/records.parquet` and
`semantic/metadata/view.json`. Each row has normalized_message plus architecture_id
and rank for validation only. Models see only normalized_message. Fold/lineage,
normalizer, counts, exact membership digests, file hashes, builder/source identities,
creation time and git state travel with the bundle. No raw paths or labels are needed
on Colab. Bundle checksum supplied out of band is the trust anchor; SHA checks alone
cannot establish authenticity if an attacker replaces both files and manifests.

Validator rejects extra/missing files and columns, label sidecars, target architecture,
wrong/duplicate ranks, membership/count mismatches, checksum changes and external
paths/symlinks. It does not infer semantic truth from lexical words like “error”.
Source-label status remains UNRESOLVED_DENY. No target evaluation data/labels are
consumed; target role in another fold never grants access within the held-out fold.
