# Dataset manifests

Version-controlled JSON manifests are written here only after raw files are present and accepted. A manifest contains relative paths, sizes, SHA-256 digests, and a deterministic dataset fingerprint.

- `hdfs_manifest.json` — verified fingerprint `0103c63b2847ba98b0b309a9e06eebb80ac8030e2f92d1f62320742537a34013`.
- `bgl_manifest.json` — verified fingerprint `c9ee7a8db13d37c88f896e305ed12dc7a66b586cdae4e388db4949f78afbe861`.

Raw bytes remain ignored and local. Manifest acceptance does not imply parsing or model readiness.
